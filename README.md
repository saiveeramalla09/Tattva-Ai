## 1. Project Overview

The AI Research Assistant helps users understand, compare, and verify information across multiple research papers.

Users can upload multiple research-paper PDFs, ask research questions, generate summaries, and compare findings across papers.

Unlike a conventional AI summarizer, this system follows a **Generator–Verifier architecture**.

The system does not simply generate an answer. It also:

1. Extracts relevant information from uploaded research papers.
2. Generates structured summaries and cross-paper comparisons.
3. Breaks generated content into independently verifiable atomic claims.
4. Retrieves relevant passages from the original research papers.
5. Classifies each claim as:
   - **Supported**
   - **Contradicted**
   - **Unresolved**
6. Provides exact evidence references so users can inspect the original source.

### Core principle

**Every factual claim generated by the system should be traceable to evidence in the uploaded research papers.**

## 2. System Architecture

We will follow a **Modular Monolith Architecture**.

This means we will have one backend application, but its internal responsibilities will be separated into independent modules.

We are not building separate microservices for each module because that would introduce unnecessary deployment, networking, and integration complexity for our current scope.
